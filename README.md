🛡️ SafeRoute — Safe Route Planner

SafeRoute is a smart women-safety platform that recommends safer routes, not just the shortest routes, by analyzing real-time and location-based safety factors.

🚀 What It Does

- 🗺️ Generates multiple routes using map & routing services
- 🚨 Analyzes available crime and safety data
- 💡 Considers street-lighting conditions
- 👮 Locates police stations, hospitals & emergency services
- 📊 Calculates a route safety score
- 🛡️ Recommends the comparatively safer route
- 📍 Provides location-based safety information

⚙️ How It Works

Start + Destination
        ↓
Map & Route Data
        ↓
Crime + Lighting + Location + Emergency Data
        ↓
Risk & Safety Analysis
        ↓
Safety Score
        ↓
Safer Route Recommendation

🛠️ Tech Stack

Frontend: HTML • CSS • JavaScript
Maps: OpenStreetMap (OSM) • Routing/Map APIs
Data: Public/Government Safety Data • Geospatial APIs
Development: Git • GitHub • VS Code

🌐 Data Sources

Designed to integrate real-time/API-based and publicly available data wherever available, including mapping, crime, lighting and emergency-service information.

🔮 Future Scope

AI-based risk prediction • Real-time alerts • Community reports • Time-based risk analysis • Mobile app • Multilingual & voice assistance

🎯 Vision

«Don't just find the shortest route. Find a route that considers safety.»

⚠️ SafeRoute is a decision-support is gives relatively safer route based on available data and does not guarantee personal safety.
